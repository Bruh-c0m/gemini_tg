# Gemini Telegram Bot

Telegram-бот принимает текст или фотографию задачи, отправляет её в Gemini и
возвращает подробное решение на русском языке. Формулы выводятся Unicode-текстом,
чтобы их было удобно читать в Telegram и в уведомлениях на часах.

## Возможности

- решение задач по тексту;
- распознавание и решение задач по фотографии;
- поддержка изображения, отправленного как файл;
- постраничная выдача длинного ответа частями до 900 символов для чтения в
  уведомлениях Android и на часах;
- ограничение доступа по Telegram ID;
- безопасное хранение токенов в переменных окружения.

## Переменные окружения

Обязательные:

- `TELEGRAM_TOKEN` — новый токен от `@BotFather`;
- `GEMINI_API_KEY` — ключ из Google AI Studio.

Рекомендуемые:

- `ALLOWED_USER_IDS` — Telegram ID через запятую, например `123456789`;
- `GEMINI_MODEL` — модель Gemini, по умолчанию `gemini-3.8-flash`;
- `MAX_PARALLEL_REQUESTS` — число одновременных запросов, по умолчанию `2`;
- `LOG_LEVEL` — уровень журналирования, по умолчанию `INFO`.

Настоящие ключи нельзя добавлять в GitHub. Если токен уже публиковался или
отправлялся в переписке, отзовите его через `/revoke` у `@BotFather` и создайте
новый.

## Развёртывание на Railway

1. В Railway выберите **New Project → Deploy from GitHub repo**.
2. Подключите этот репозиторий.
3. В сервисе откройте **Variables** и добавьте `TELEGRAM_TOKEN`,
   `GEMINI_API_KEY` и `ALLOWED_USER_IDS`.
4. Если Railway не определит команду автоматически, в **Settings → Deploy →
   Custom Start Command** укажите `python main.py`.
5. Запустите развёртывание и проверьте журнал.

Публичный домен и переменная `PORT` не нужны: бот получает сообщения через
Telegram Long Polling. Сервис должен быть запущен в одном экземпляре.

## Проверка бота

1. Отправьте `/start`.
2. Отправьте `/id`, чтобы узнать свой Telegram ID.
3. Укажите полученное число в `ALLOWED_USER_IDS` на Railway и перезапустите
   сервис.
4. Отправьте текстовую задачу.
5. Отправьте фотографию задачи. Для мелких формул лучше отправлять изображение
   как файл без сжатия.
6. Если ответ состоит из нескольких частей, отвечайте боту словом `дальше` или
   командой `/next`. Бот будет присылать по одной части отдельным уведомлением.

## Локальный запуск

Требуется Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:TELEGRAM_TOKEN = "НОВЫЙ_ТОКЕН"
$env:GEMINI_API_KEY = "КЛЮЧ_GEMINI"
$env:ALLOWED_USER_IDS = "ВАШ_TELEGRAM_ID"
python main.py
```

Тесты запускаются командой:

```powershell
python -m unittest -v
```
