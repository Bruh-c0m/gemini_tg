# Gemini Telegram Bot

Telegram-бот принимает текст или фотографию задачи, отправляет её в Gemini и
возвращает краткое, но полное решение на русском языке. Формулы выводятся Unicode-текстом,
чтобы их было удобно читать в Telegram и в уведомлениях на часах.

## Возможности

- решение задач по тексту;
- распознавание и решение задач по фотографии;
- поддержка изображения, отправленного как файл;
- компактное изложение без повторов; для билета из нескольких задач бот решает
  каждую задачу полностью, не применяя жёсткий предел общей длины;
- постраничная выдача длинного ответа частями до 900 символов для чтения в
  уведомлениях Android и на часах;
- переход вперёд и назад по сохранённым частям командами `/next` и `/back`;
- одновременная работа с несколькими пользователями;
- автоматические повторы того же запроса при перегрузке Gemini;
- безопасное хранение токенов в переменных окружения.

## Переменные окружения

Обязательные:

- `TELEGRAM_TOKEN` — новый токен от `@BotFather`;
- `GEMINI_API_KEY` — ключ из Google AI Studio.

Рекомендуемые:

- `GEMINI_MODELS` — модели Gemini через запятую; по умолчанию
  `gemini-3.5-flash,gemini-3.1-flash-lite`. При перегрузке бот сам переключается
  на следующую модель;
- `MAX_PARALLEL_REQUESTS` — число одновременных запросов, по умолчанию `4`;
- `LOG_LEVEL` — уровень журналирования, по умолчанию `INFO`.

Настоящие ключи нельзя добавлять в GitHub. Если токен уже публиковался или
отправлялся в переписке, отзовите его через `/revoke` у `@BotFather` и создайте
новый.

## Развёртывание на Railway

1. В Railway выберите **New Project → Deploy from GitHub repo**.
2. Подключите этот репозиторий.
3. В сервисе откройте **Variables** и добавьте `TELEGRAM_TOKEN`
   и `GEMINI_API_KEY`.
4. Если Railway не определит команду автоматически, в **Settings → Deploy →
   Custom Start Command** укажите `python main.py`.
5. Запустите развёртывание и проверьте журнал.

Публичный домен и переменная `PORT` не нужны: бот получает сообщения через
Telegram Long Polling. Сервис должен быть запущен в одном экземпляре.

## Проверка бота

1. Отправьте `/start`.
2. Отправьте текстовую задачу.
3. Отправьте фотографию задачи. Для мелких формул лучше отправлять изображение
   как файл без сжатия.
4. Если ответ состоит из нескольких частей, используйте `/next` или слово
   `дальше` для перехода вперёд. Команда `/back` или слово `назад` возвращает к
   предыдущей части. После возврата можно снова двигаться вперёд по тому же
   ответу; последняя часть не удаляет сохранённую навигацию.

## Локальный запуск

Требуется Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:TELEGRAM_TOKEN = "НОВЫЙ_ТОКЕН"
$env:GEMINI_API_KEY = "КЛЮЧ_GEMINI"
python main.py
```

Тесты запускаются командой:

```powershell
python -m unittest -v
```
